Seletores


O que são seletores CSS?


Um seletor CSS é um padrão ou símbolo usado para indicar ao navegador quais elementos HTML de uma página devem receber os estilos definidos


Seletor de atibuto


seletor de atributo no CSS serve para encontrar e estilizar elementos HTML com base na presença de um atributo específico ou no valor que esse atributo possui, sem depender exclusivamente de classes (.) ou IDs (#).


exemplo

a[target] {

background-color: yellow;


img[alt] {

border: 3px solid #3498db;}

}


Seletor de Descendente


seletor de descendente no CSS serve para encontrar e estilizar elementos HTML que são descendentes de outro elemento, ou seja, estão dentro dele hierarquicamente.


exemplo

.container p {

color: blue;

font-weight: bold;

}


Seletor filho Direto


O seletor de filho direto (representado pelo símbolo de maior que >) seleciona apenas os elementos que são filhos imediatos de um elemento pai específico


exemplo

.pai > p {

color: #e74c3c; /* Vermelho */

font-weight: bold;

}


Seletor Adjacente Direto


O seletor de adjacente direto (representado pelo símbolo de mais +) seleciona um elemento que é imediatamente adjacente a outro elemento específico, ou seja, o primeiro elemento que vem logo após o segundo na hierarquia do HTML.

exemplo

.pai + p {

color: #2ecc71; /* Verde */

font-weight: bold;

}


Seletor de irmãos Gerais


O seletor de irmãos gerais (representado pelo símbolo de til ~)seleciona todos os elementos que são irmãos de um elemento específico, ou seja, todos os elementos que compartilham o mesmo pai e vêm depois do elemento especificado na hierarquia do HTML.

exemplo

.pai ~ p {

color: #f39c12; /* Laranja */

font-weight: bold;

}


Seletor de Pseudoclasses


O seletor de pseudoclasse no CSS serve para selecionar elementos HTML com base em seu estado ou posição em relação a outros elementos, permitindo aplicar estilos específicos a esses elementos sem a necessidade de adicionar classes ou IDs adicionais.

exemplo

a:hover {

color: red;

}


Seletor de Pseudoelementos


O seletor de pseudoelementos no CSS serve para selecionar e estilizar partes específicas de elementos HTML, como o primeiro caractere de um parágrafo ou o conteúdo antes de um elemento.

exemplo

p::first-letter {

color: #e74c3c; /* Vermelho */

font-size: 2em;

}
